# Anonymisation and responsible sharing

The public example is an anonymised visualisation only. It excludes participant
names, identifiers, dates, raw files, model parameters, and aggregate model
performance results. It includes one authorised anonymised reference-versus-
prediction comparison solely to make the analysis path understandable.

The visualisation is shared to explain the research workflow, not to support a
clinical interpretation. The underlying code, data, and experimental results
are not distributed in this repository.
