# Software overview

The research software follows a simple conceptual sequence:

1. Record multi-wavelength optical signals from the embedded prototype.
2. Prepare the recording for analysis.
3. Assess signal quality and identify an appropriate analysis segment.
4. Generate a research-oriented model output.

The public showcase intentionally does not disclose the implementation,
source code, feature definitions, tuning choices, validation procedure, or
numerical performance. Those materials remain private while the academic work
is being prepared.
